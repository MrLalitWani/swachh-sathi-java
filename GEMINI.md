# Antigravity Project Context

Read `AGENTS.md` at the repository root before working. It is the shared engineering policy for this project.

## Antigravity operating rules
- Inspect the repository and current Git changes before editing.
- Identify the real Java/build/framework versions from repository files.
- Plan meaningful changes before implementation; ask for approval before broad or destructive changes.
- Follow existing architecture and conventions. Do not invent modules, commands, dependencies, or configuration.
- Prefer focused edits and add/update tests.
- Verify with repository-defined commands; report exactly what ran.
- Never expose secrets. Ask before deployments, destructive operations, production data changes, or force pushes.

## Java project focus
Use the Java and (if present) Spring Boot guidance in `AGENTS.md`. Treat Spring-specific guidance as conditional: do not assume this is a Spring Boot project.
